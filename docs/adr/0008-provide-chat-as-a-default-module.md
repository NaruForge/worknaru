# 0008. Chat을 첫 기본 제공 모듈로 제공

- 날짜: 2026-09-08
- Status: Accepted
- 관련 Work Item: [#3 WorkNaru 플랫폼 초기 아키텍처 설계](https://github.com/NaruForge/worknaru/issues/3)
- 관련 ADR: [0001. ACP 채택](0001-use-acp-for-agent-connections.md), [0006. Module의 업무 서비스 경계](0006-define-modules-as-business-services.md), [0007. 업무 데이터와 AI Session 분리](0007-separate-business-data-from-ai-sessions.md)
- 관련 문서: [Chat과 기본 제공 모듈](../../README.md#첫-기본-제공-module-chat), [프로젝트 기록 규약](../project-records.md)

## Context

Chat은 이미 첫 Module로 정해져 있었으나 사용자에게 어떻게 제공하는지는 명시하지 않았다. Module을 연결하는 방식을 논의하면서, 제품에 포함되는 서비스와 사용자가 추가하는 서비스를 별도 종류로 나눌지 검토했다.

같은 Module 개념과 책임 경계를 유지하고 제공 방식만 구분하면, 기본 제공 서비스로 공통 기반을 검증하면서 다른 업무 서비스를 추가할 수 있다. 사용자는 ‘내장 모듈’이라는 용어를 쉽게 설명해 달라고 요청했다. WorkNaru 설치 시 처음부터 함께 제공되는 서비스라는 의미로 ‘기본 제공 모듈’을 설명한 뒤 Chat의 위치를 결정했다.

Chat을 별도로 추가하도록 하면 초기 설치에 포함할 기능은 줄지만, 첫 대화를 시작하기 전에 Module을 준비해야 한다. Chat을 함께 제공하면 사용자가 별도 Module 추가 없이 대화 기능에 접근하고, 개발 과정에서도 첫 Module로 공통 AI 실행 기반을 검증할 수 있다. AI 에이전트 자체의 설치·인증까지 자동으로 완료된다는 뜻은 아니다.

## Decision

**Chat을 WorkNaru 설치 시 함께 제공하는 첫 기본 모듈로 정한다.** 제품 설명에서는 ‘기본 제공 모듈’이라는 용어를 사용하며, 의미와 Chat의 책임은 [README](../../README.md#첫-기본-제공-module-chat)에 둔다.

기본 제공 여부는 Module의 제공 방식에 관한 구분이다. Chat도 다른 Module과 같은 업무 서비스 경계를 따르며, 대화의 사용자 경험을 담당하고 플랫폼의 공통 AI 연결·Session·실행 기능을 이용한다. 다른 Module이 AI 기능을 사용하기 위해 Chat을 경유하도록 만들지 않는다.

### 승인 근거

2026-09-08 기본 제공 모듈을 WorkNaru 설치 시 함께 들어 있는 서비스로 설명하고, 사용자 추가 모듈과 둘 다 같은 Module임을 확인했다. Chat을 첫 기본 제공 모듈의 예로 든 설명에 사용자가 다음과 같이 결정했다.

> 동의해. Chat이 기본 모듈이야.

이 사용자 결정을 근거로 `Accepted`로 기록한다.

### 이번 결정에서 확정하지 않는 사항

- Module 등록·활성화 API, 실행 프로세스와 패키징 방식
- 사용자 추가 모듈의 설치·업데이트·제거, 배포 경로와 신뢰·권한 정책
- Chat의 비활성화·제거 가능 여부, 최초 화면과 자동 실행 동작
- Chat의 상세 기능 명세와 다른 기본 제공 모듈의 선정

## Consequences

- 사용자는 Chat Module을 별도로 추가하는 절차 없이 대화 기능에 접근할 수 있다. 실제 AI 사용에 필요한 에이전트 연결·인증 흐름은 별도로 제공해야 한다.
- Chat의 구현과 배포 검증을 WorkNaru의 기본 제공 범위에 포함한다. 기본 제공이라는 이유로 업무 기능과 플랫폼의 공통 실행 책임을 합치지 않는다.
- Chat으로 공통 기반을 먼저 검증하되, 다른 업무 서비스가 Chat에 의존하지 않고 플랫폼을 사용할 수 있는지 후속 설계에서 확인한다.

이번 결정은 Chat의 제공 방식과 Module로서의 위치를 확정한다. 외부 Module 설치 체계나 제품 구현 완료를 의미하지 않는다.
