# 0004. 초기 지원 환경을 Windows로 설정

- 날짜: 2026-09-08
- Status: Accepted
- 관련 Work Item: [#3 WorkNaru 플랫폼 초기 아키텍처 설계](https://github.com/NaruForge/worknaru/issues/3)
- 관련 ADR: [0002. Daemon 중심 코어와 웹·데스크톱 공통 접속 구조](0002-use-daemon-core-with-web-and-desktop-clients.md)
- 관련 문서: [제품 방향](../../README.md), [프로젝트 기록 규약](../project-records.md)

## Context

Daemon과 데스크톱 앱의 실행·종료, 에이전트 프로세스 관리, 파일 경로 및 배포 방법은 지원 운영체제의 영향을 받는다. 초기 구현에서 여러 운영체제를 동시에 지원할지, 우선 지원 환경을 정할지 선택해야 한다.

여러 운영체제를 처음부터 지원하면 사용 범위를 넓힐 수 있지만 설치·실행·종료·복구 검증 범위도 함께 늘어난다. 우선 환경을 정하면 플랫폼의 기본 구조와 사용 흐름을 집중해서 검증할 수 있다.

## Decision

**WorkNaru의 초기 지원·검증 환경은 Windows를 우선으로 한다. 다른 운영체제의 지원 여부와 시기는 미정으로 둔다.**

Daemon과 데스크톱 앱의 초기 구현·설치·실행 검증은 Windows를 기준으로 구체화한다. 이 결정은 Windows 전용 제품으로 영구 제한하거나 특정 언어·프레임워크를 채택하는 결정이 아니다.

Web UI와 Daemon의 접속 경계는 ADR-0002를 따른다. Web UI를 제공한다는 사실만으로 다른 운영체제에서의 Daemon·데스크톱 앱 지원이 확정되는 것은 아니다.

### 승인 근거

2026-09-08 지원 환경에 대한 질문에 사용자가 다음과 같이 명시했다.

> 일단 Windows가 기본값. 나머지는 미정.

이 사용자 결정을 근거로 `Accepted`로 기록한다.

### 후속 설계로 남기는 사항

- 최소 Windows 버전과 CPU 아키텍처
- 개발 언어, 실행 런타임, 데스크톱 프레임워크와 설치·업데이트 방식
- 지원 브라우저와 운영체제별 추가 지원 계획

## Consequences

- Windows에서 ACP 에이전트 연결과 프로세스 관리, 앱 종료 정책을 우선 검증할 수 있다.
- 초기부터 여러 운영체제의 패키징과 실행 차이를 모두 해결할 필요를 줄인다.
- 이후 다른 운영체제를 지원할 경우 경로·프로세스·배포 방식의 차이를 구현하고 검증해야 한다.
- 기술 스택 선정 시 Windows에서의 실행·배포 적합성을 평가해야 한다. 다른 운영체제에서의 동작은 별도의 검증 없이 보장하지 않는다.

진행 상태와 후속 작업의 범위는 관련 GitHub Issue와 전용 Project에서 관리한다.
