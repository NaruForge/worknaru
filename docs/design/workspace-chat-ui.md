# 공통 작업 화면의 설계 기록과 현재 Chat UI 기준

- 시안 기준일: 2026-09-09
- 현재 Chat 동작 반영: 2026-09-10
- 화면 구조의 결정 및 승인 근거: [ADR-0014](../adr/0014-separate-service-navigation-from-module-navigation.md)
- 제품 책임: [README](../../README.md)
- 실제 Daemon 기능과 한도: [개발 안내](../development.md)

사용자가 검토한 A안 상세 시안의 선택 근거를 보존하고, Paseo 전환 후 현재 Chat에 적용하는 동작을 구분한다. 아래 시안의 전체 탐색·Settings·파일 diff 구성이 현재 제품에 모두 구현됐다는 뜻은 아니다. 작업 내용과 진행 상태는 프로젝트 기록 규약에 따라 GitHub에서 관리한다.

## 현재 Paseo 기반 Chat

현재 제품 범위는 [#35](https://github.com/NaruForge/worknaru/issues/35), 실행·계약·저장과 복구는 [개발 안내](../development.md)를 따른다. 배색·공통 control·입력창 위의 접힌 권한 패널은 [Design System](design-system.md)의 승인 기준을 사용한다.

| 항목 | 현재 동작 |
| --- | --- |
| 화면 범위 | 대화 목록·본문, 모델·추론 선택, 도구 권한 1회 허용·거절과 취소를 제공한다. 전체 서비스 탐색·Settings·파일 diff는 과거 시안의 범위다. |
| 입력 | 앞뒤 공백을 제거한 뒤 1~32,000의 문자열 길이를 Daemon이 검사한다. 길이는 JavaScript의 UTF-16 코드 단위 기준이며 UTF-8 바이트 수가 아니다. Enter 전송·Shift + Enter 줄바꿈·한글 조합 중 전송 방지를 유지한다. |
| 취소 | 취소 접수와 실제 종료를 구분한다. 해당 입력의 종료가 확인되고 Daemon이 입력 가능 상태를 반환하면 같은 대화에서 다시 입력할 수 있다. |
| 재시작 | 같은 데이터·Workspace에서 기록을 다시 조회하고, 정상 완료가 확인된 대화는 기존 맥락을 이어갈 수 있다. 종료 증거를 놓친 입력은 결과 불명으로 유지하고 자동 재실행하지 않는다. |
| 초안 | 열린 화면에서 대화별 미전송 초안을 유지한다. 첫 전송의 초안은 생성된 대화로 옮기고 생성 실패 시에도 그 대화에 남긴다. 미전송 본문을 브라우저 새로고침 후 복원하는 기능은 제공하지 않는다. |

다음 절부터는 **당시 승인·검증한 시안의 기록**이다. 입력 한도·상태별 조치와 제공 화면의 현재 동작은 위 표와 개발 안내를 우선한다.

## 시안의 화면 배치

상단에는 제품 이름, 현재 Workspace와 연결 상태를 표시한다. 왼쪽 서비스 탐색은 플랫폼이, 그 옆의 목록과 주 작업 영역은 Module이 구성한다. 첫 Chat의 목록에는 대화 제목, 실행 또는 기록 보기 상태, 작성 중인 초안 여부를 표시한다.

| 영역·조건 | 상세 시안의 기준 |
| --- | --- |
| 서비스 탐색 | 너비 64px. 아이콘과 이름을 함께 표시한다. |
| 대화 목록 | 기본 240px. 목록만 독립적으로 접거나 펼친다. |
| 화면 너비 860px 이상 | 서비스 탐색·대화 목록·본문을 함께 배치한다. 목록을 접으면 본문이 넓어진다. |
| 860px 미만 | Module 선택·목록·Main을 한 단계씩 표시한다. 항목 선택으로 Main에 들어가고 큰 목록 복귀 버튼으로 돌아간다. |
| 목록이 없는 Module | Module 목록을 생략하고 서비스 탐색 옆부터 본문을 사용한다. |

치수는 CSS px이며 창 안에서 UI에 할당된 너비를 기준으로 한다. 시안의 200–280px 목록 너비 조절과 창 크기 선택은 설계 비교용이다. 사용자가 드래그로 너비를 바꾸는 제품 기능의 승인을 뜻하지 않는다.

시안의 절제된 녹색 강조색, 밝은·어두운 배경, 본문과 상태 안내의 구분을 기준으로 한다. 일반 대화 본문과 입력은 14px, 좁은 화면의 터치 입력은 16px로 검토했다. 색만으로 상태를 구분하지 않고 문구와 아이콘을 함께 사용한다.

설정은 화면·연결·AI로 나눈 전용 메뉴를 가진 독립된 플랫폼 화면이다. Chat의 대화 목록을 사용하지 않는다. 배색·공통 control과 파일 승인 배치는 [Design System](design-system.md)의 사용자 선택을 따른다.

## 시안의 탐색과 입력

- 목록을 접어도 현재 대화와 입력 초안을 유지한다. 다른 대화나 Module로 이동한 뒤 돌아오면 해당 대화의 초안을 복원한다.
- 좁은 화면에서 목록과 Main을 이동할 때 현재 단계로 포커스를 옮긴다. 목록 복귀 버튼과 브라우저 뒤로·앞으로 가기를 지원하고 목록 스크롤과 선택을 유지한다. 전체 화면 목록은 Modal이 아니며 Tab을 가두지 않는다. 당시 시안에 포함한 연결·개발 종료 Dialog는 포커스 제한과 Escape·포커스 복귀를 유지한다.
- Enter는 전송, Shift + Enter는 줄바꿈이다. 한글 조합 중 Enter로 전송하지 않는다.
- 응답 중에도 다음 질문의 초안을 작성할 수 있다. 이때 Enter는 실행을 취소하거나 새 실행을 만들지 않는다. 중지는 별도 버튼으로 요청한다.
- 접수 확인 중에는 중복 전송을 막는다. 취소 접수 후에는 실제 종료 확인까지 ‘중지 중’으로 표시한다.
- 시안 당시에는 UTF-8 16KiB 입력 한도로 검토했다. 초과 시 내용을 유지하며 줄일 필요가 있음을 안내했다. 현재 입력 한도는 위의 Paseo 기반 Chat 설명을 따른다.

초안의 브라우저 새로고침·앱 재실행 후 보존, 장기 보관 위치와 접수 미확정 요청의 영속 보존 방식은 실제 접속 구현에서 정한다. 시안은 열린 화면 안의 메모리에서만 초안을 유지했다.

## 시안의 실행·오류 표시

| 상황 | 표현과 사용자 조치 |
| --- | --- |
| 새 대화 | 입력할 수 있는 빈 화면과 새 대화임을 표시한다. |
| 접수 확인 중 | 접수 결과를 기다리는 메시지를 표시하고 중복 전송을 막는다. |
| 응답 중 | 저장을 확인한 답변을 표시하며 중지 버튼을 제공한다. |
| 중지 중 | 종료 확인을 기다리며 취소 완료로 미리 표시하지 않는다. |
| 중지 완료 | 저장된 부분을 유지하고 당시 연결 정책에 따라 새 대화를 안내한다. |
| 연결 끊김 | 마지막 확인 기록을 표시하고 재연결을 제공한다. 대화를 전환해도 연결 장애 안내를 유지한다. |
| 접수 여부 불명 | 기존 요청의 접수를 조회한다. 새 요청으로 자동 재전송하지 않는다. |
| AI 연결 실패 | 저장된 답변을 유지하고 새 대화를 안내한다. |
| 저장 확인 불가 | 마지막 저장 확인 내용만 표시하고 새 전송을 막는다. 기록 상태 확인을 제공한다. |
| 실행 종료 불명 | 해당 대화의 새 실행을 막고 실행 상태 확인을 제공한다. |
| 재시작 후 기록 보기 | 기록을 볼 수 있음을 알리고 새 대화를 안내한다. 기존 맥락의 재개를 약속하지 않는다. |
| AI 연결 한도 | 현재 연결 한도를 설명하고 연결이 유지된 다른 대화 선택을 제공한다. |

UI의 상태 이름은 사용자를 위한 표현이며 새로운 플랫폼 실행 상태를 추가하는 명세가 아니다. 기록·실행·연결의 원본은 Daemon이고, 조회 결과에 따라 안내와 가능한 조치를 갱신한다. 시안의 ‘상태 확인’ 버튼이 성공 결과로 바뀌는 동작과 타이머는 가상 동작이다. 실제 구현에서 같은 결과나 지연 시간을 고정하지 않는다.

## 시안 검증의 범위

밝은·어두운 테마, 넓은 화면·736px·390px와 320px에서 배치를 확인했다. 목록 접기, 좁은 창의 서비스 접근, 포커스 이동과 Escape, 대화별 초안, 한글 조합·입력 한도, 접수·중지와 오류별 조치를 브라우저에서 검증했다.

실제 Daemon 접속, 인증, 재접속 후 데이터 일관성, 페이지 조회와 긴 대화의 스크롤, 영구 저장 및 보조 기술 전반의 접근성 검증은 제품 구현에서 수행해야 한다. 보고서 화면은 목록이 없는 Module의 배치 예시이며 기능 구현 대상이 아니다.
