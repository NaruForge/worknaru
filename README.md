# WorkNaru

**WorkNaru는 다양한 AI 기반 업무 기능을 Module로 추가하고 조합할 수 있는 확장 가능한 AI Workspace입니다.**

사용자는 하나의 Workspace 안에서 AI 에이전트, 도구, 파일, 프로젝트와 상호작용하며 작업합니다. 필요한 업무 기능은 독립적인 Module을 통해 확장하며, 플랫폼은 특정 업무 영역이나 문서 처리에 종속되지 않습니다.

## 플랫폼과 Module

WorkNaru는 공통 실행 기반을 제공하는 **플랫폼**과 실제 업무 능력을 제공하는 **Module**로 구성됩니다.

### 플랫폼: 공통 기반

플랫폼은 각 Module이 함께 사용할 수 있는 작업 환경과 AI 실행 기반을 제공합니다. 공통 기반에는 다음과 같은 역할이 포함될 수 있습니다.

- Workspace와 프로젝트 관리
- AI 에이전트 연결, 대화와 작업 실행
- 도구 사용과 사용자 승인
- 파일과 결과물 관리
- 실행 상태와 기록 관리
- 설정과 확장 기능 관리

이 목록은 처음부터 모두 구현해야 할 기능 명세가 아닙니다. 실제 Module을 만들고 검증하는 과정에서 필요한 공통 기반을 점진적으로 갖춥니다.

### Module: 독립적인 업무 기능

Module은 구체적인 업무 기능과 그에 필요한 흐름을 소유하며, 플랫폼이 제공하는 공통 기반 위에서 동작합니다.

Chat, 문서 검수, 문서 질의응답, 보고서 생성은 Module의 예시입니다. 이들은 WorkNaru 위에서 제공할 수 있는 개별 기능이며, WorkNaru 전체의 정체성이나 업무 범위를 한정하지 않습니다.

Module마다 업무의 성격과 사용 방식은 달라질 수 있습니다. 특정 Module의 요구가 플랫폼 전체나 다른 Module의 구조를 결정하지 않도록 책임을 나눕니다.

## 첫 번째 Module: Chat

첫 번째 Module은 가장 단순한 Chat입니다. 사용자가 AI 에이전트와 대화하는 흐름을 통해 공통 AI 실행 환경과 Module 구조를 먼저 검증합니다.

Chat 역시 플랫폼 위에서 동작하는 하나의 Module입니다. 이후 서로 다른 성격의 Module을 추가하며, 기존 기반을 어디까지 공유할 수 있는지와 각 Module이 소유해야 할 책임을 확인합니다.

## 설계 원칙

- **코어는 작고 안정적으로 유지합니다.** 실제로 필요한 공통 기반에 집중합니다.
- **업무 능력은 Module이 소유합니다.** 업무별 기능과 흐름은 해당 Module 안에서 발전시킵니다.
- **새로운 Module을 독립적으로 추가할 수 있어야 합니다.** 기존 Module이나 플랫폼 코어를 크게 수정하지 않고 기능을 확장할 수 있는 구조를 지향합니다.
- **공통화는 실제 요구를 바탕으로 합니다.** 미래의 모든 Module을 예측해 거대한 범용 프레임워크를 미리 만들지 않습니다.
- **다양한 Module로 구조를 검증합니다.** Chat에서 시작해 성격이 다른 업무 기능을 추가하면서 플랫폼을 점진적으로 확장합니다.
